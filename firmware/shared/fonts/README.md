`Antonio-Bold.ttf` is Antonio by Vernon Adams (https://fonts.google.com/specimen/Antonio),
licensed under the SIL Open Font License 1.1 (`OFL.txt`): a static instance at weight 700,
cut from the variable font with fontTools (`varLib.instancer`, wght=700) and saved as plain
TTF. 235 glyphs, Latin only, which is why the hub reduces every string to capitals in
plain ASCII before sending it: LVGL's tiny_ttf draws nothing for a glyph the face lacks.
